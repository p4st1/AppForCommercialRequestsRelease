# AppForCommercialRequests

Автоматизация поиска закупок, анализа заявок и подготовки коммерческих предложений для электронных торговых площадок.

## Системные требования

- Windows 10/11 (x64) | MacOS arm64/x86
- Подключение к интернету
- Действующий аккаунт на поддерживаемой торговой площадке
